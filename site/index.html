A few things
you might wonder.

Can I use Mawl today?

Yes, if you're comfortable self-hosting an early project. The repository includes Docker Compose setup instructions. The Windows desktop experience is still in development; there isn't a ready desktop installer here yet.

Read the setup guide
Do I need a particular AI subscription?

You can use an API key for a supported provider, or a local model through Ollama. Mawl also includes ChatGPT sign-in and a Claude plan connection. Provider access, subscriptions, and usage charges depend on the connection you choose.

Where do my conversations go?

Mawl stores its data on the machine where you host it. When you use a cloud model, prompts are sent to that provider under its terms. If you choose a local Ollama model, model inference can stay on your machine too.
